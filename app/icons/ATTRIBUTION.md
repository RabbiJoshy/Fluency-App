# Source icons

- `tatoeba.svg`: “Tatoeba Logo” by Carvogu, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). [Original file](https://commons.wikimedia.org/wiki/File:Tatoeba_Logo.svg). The file is unmodified.
- `wikipedia-w.svg`: “Wikipedia's W” by Jonathan Hoefler, [file and trademark information](https://commons.wikimedia.org/wiki/File:Wikipedia%27s_W.svg). The file is unmodified. Used as the requested W mark for dictionary-source chips; those chips are labelled Wiktionary in text for accessibility.
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`: placeholder home-screen icon, our own. The app's "F" mark (Space Grotesk 700, Spanish-red `#C8102E` on the dark base `#0a0e14`), rendered to PNG because iOS ignores SVG home-screen icons. Replace when a real logo is chosen.
